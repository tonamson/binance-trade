Quản lý vốn

BINANCE SPOT TERMINAL

Theo dõi giá vốn trung bình, lãi/lỗ thực tế và các lệnh Spot đang chờ khớp theo thời gian thực.

  • Chỉ đọc dữ liệu (Read-only) Chỉ dùng quyền xem tài khoản và lịch sử lệnh; không đặt hay hủy lệnh.
  • Lưu trữ cục bộ 100% Lịch sử lưu trong SQLite OPFS trên máy. Key chỉ gửi tới api.binance.com.

Hướng dẫn 3 bước lấy API Key

  1. Mở Binance → Tài khoản → Quản lý API → Tạo API.
  2. Chỉ giữ bật Cho phép đọc (Enable Reading). Tắt giao dịch và rút tiền.
  3. Dán API Key và Secret Key vào khung bên cạnh.

Kết nối tài khoản

Key lưu trong chrome.storage.local không mã hóa trên đĩa.

Xem thử giao diện với dữ liệu mẫu →

Dashboard đang mở ở tab khác

Cơ sở dữ liệu SQLite OPFS chỉ cho phép một kết nối tại một thời điểm. Hãy dùng tab đang mở hoặc đóng tab kia rồi thử lại.
